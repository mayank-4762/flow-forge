# FlowForge — Automation Company Website

Production-style static marketing site for a parent automation company/catalog.

## Included
- Responsive landing page
- Automation catalog
- AdmissionFlow product
- Maintenance Autopilot product
- Logistics, B2B, service and manufacturing automation cards
- Featured workflow visualization
- Deployment model
- Assessment modal/form shell
- No external runtime dependencies

## Important
The assessment form is intentionally demo-only until a real CRM/email endpoint is connected.
